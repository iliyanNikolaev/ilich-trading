# Ilich Trading Academy

Образователно уеб приложение на български език за основите на трейдинга, техническия анализ, пазарната структура, стратегии и управление на риска.

## Стартиране локално

Приложението зарежда страниците чрез Fetch API. Затова го стартирай през локален HTTP сървър, а не чрез директно отваряне на `index.html` с `file://`.

### Вариант 1: Python

1. Отвори терминал в папката `client`.
2. Изпълни:

```bash
python -m http.server 8000
```

3. Отвори `http://localhost:8000` в браузъра.

### Вариант 2: VS Code

1. Отвори папката `client` във VS Code.
2. Стартирай `index.html` чрез разширението Live Server.

## Структура

- `index.html` – основната рамка, хедър и адаптивна навигация.
- `app.js` – зареждане и маршрутизиране на уроците.
- `styles.css` – общата визуална система и responsive стиловете.
- `pages/` – учебните страници.
- `images/` – оптимизирани WebP илюстрации.

## Учебни страници

1. Начало и основи на трейдинга
2. Тренд и пазарна структура
3. Подкрепа и съпротива
4. Fair Value Gap
5. EMA 50 и EMA 200
6. Единични свещни модели
7. Двойни свещни модели
8. Тройни свещни модели
9. Продължаващи модели
10. SMT дивергенция
11. AMD и Premium / Discount
12. Gold Swing Strategy – BUY и SELL
13. Управление на риска

## Бележка

Съдържанието е с образователна цел и не представлява инвестиционен съвет или сигнал за търговия. Търговията с CFD и ливъридж носи риск от загуба.
